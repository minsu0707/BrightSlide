# BrightSlide

트레이 아이콘 클릭 한 번으로 모니터 밝기를 드래그로 조절하는 **Windows 전용** 유틸리티입니다.

macOS의 메뉴바 밝기 슬라이더처럼, 별도 설정 창을 열지 않고도 바로 화면 밝기를 조절할 수 있게 만드는 것이 목표입니다.

## 상태

초기 개발 단계(MVP)입니다.

## 기능

- 시스템 트레이 상주, 아이콘 클릭 시 밝기 슬라이더 팝업 표시
- 연결된 모든 디스플레이를 자동 감지해서 모니터별 슬라이더 제공
  - 노트북 내장 디스플레이: Windows WMI(`WmiMonitorBrightnessMethods`)로 제어
  - 외장 모니터: DDC/CI(`dxva2.dll`)로 제어 — 모니터와 연결 케이블이 DDC/CI를 지원해야 동작합니다
- 슬라이더 드래그 시 디바운스를 적용해 과도한 하드웨어 호출 방지

## 요구 사항

- Windows 10/11 (x64)
- .NET 9 SDK (빌드 시)

## 실행

```powershell
dotnet run
```

## 알려진 제한 사항 (MVP)

- 자동 시작 등록, 설치 인스톨러는 아직 없습니다.
- 내장 패널이 DDC/CI도 동시에 지원하는 일부 기기에서는 밝기 슬라이더가 중복 표시될 수 있습니다.
- USB-C 허브를 경유한 외장 모니터는 DDC/CI 신호가 전달되지 않아 동작하지 않을 수 있습니다.
